# Fadi Kazaan Website

A personal barber and hairstyling website for Fadi Kazaan. The site includes a hero section with background image slides, profile branding, an about section, services cards, social media links, and a contact form.

## Pages and Sections

- Home hero section with animated background slides
- About section introducing Fadi Kazaan
- Services section for haircuts, shaving, and styling
- Contact section with form and social media links

## Built With

- HTML
- CSS
- PHP contact file

## Project Files

```text
index.html      Main website page
style.css       Website styling and responsive layout
contact.php     PHP contact form handler
img/            Website images
icones/         Social media and UI icons
```

## Contact Form Note

The contact form currently uses:

```html
mailto:
```

This opens the visitor's email app. If the website is hosted on GitHub Pages, PHP will not work because GitHub Pages only supports static files.

For a real hosted contact form, use a service like Formspree, EmailJS, or a hosting provider that supports PHP.

## Responsive Design

The website includes media queries for:

- Tablets
- Phones
- Small phones

These adjust the navigation, hero images, about layout, service cards, and contact section for smaller screens.
